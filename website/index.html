Private, On-Device AI Chat for Android

SmolChat lets you run Small Language Models (SLMs) in GGUF format directly on your Android device using llama.cpp—no cloud APIs, no internet required, and full control over prompts and inference parameters.

Get it on Google Play Download APK View Source

Built for Local SLM Inference

Designed around a clean Android interface and native C/C++ execution for fast, private conversations on your phone.

100% On-Device Execution

Runs GGUF models natively via llama.cpp compiled with the Android NDK. Your prompts and responses stay on your device.

Flexible GGUF Management

Add, remove, and switch between local GGUF models, or download models directly inside the app.

Custom Prompts & Sampling

Configure system prompts, temperature, and min-p per chat or set global defaults for all new conversations.

Downstream Tasks

Create reusable single-turn tasks for quick text generation without persisting chat history.

Markdown & Syntax Highlighting

Renders rich Markdown responses with Markwon and Prism4j, complete with one-tap copy for code blocks.

OpenAI-Compatible Server

Includes a local HTTP server capable of listing loaded models and serving OpenAI-compatible LLM inference.
